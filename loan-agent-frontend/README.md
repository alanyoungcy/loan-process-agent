# Capco Loan Collection Agent - Frontend

Professional React-based frontend for the AI-powered loan collection management system, styled with Capco's enterprise design aesthetic.

## 🎨 Design

- **Framework:** React 18 with TypeScript
- **Styling:** Tailwind CSS with Capco color palette
- **State Management:** Zustand
- **API Client:** Axios with React Query
- **Routing:** React Router v6
- **Icons:** Lucide React
- **Charts:** Recharts

## 🚀 Quick Start

```bash
cd loan-agent-frontend
npm install
npm run dev
```

Visit **http://localhost:3000**

**Default Credentials:**
- Admin: `admin` / `admin123`
- Collector: `collector1` / `admin123`

## 📁 Key Features

✅ Dashboard with real-time statistics
✅ Case management with advanced search
✅ AI-powered script generation
✅ Customer intent analysis
✅ Willingness to pay scoring
✅ Responsive Capco-branded design
